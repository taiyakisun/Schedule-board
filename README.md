# Schedule-board

Schedule-boardは、親子グループ、進捗、着手日、階層TODO、期限通知、Excel出力に対応した簡易ガントチャートアプリです。

Python標準のTkinter/ttkを使い、落ち着いたニュートラル配色、状態バッジ、選択ストライプ、進捗ミニバー、週末と今日を見分けやすい時間軸を備えたモダンUIにしています。

## 実行方法

- 前提: Python 3.10以降（tkinter同梱）
- 実行: `python sch_gantt_main.py`
- 外部Pythonパッケージは不要です。

## アイコン

- `assets/sch_gantt_icon.png`: ホームページなどでも使える1024×1024のマスター画像
- `assets/sch_gantt_icon.ico`: WindowsのタイトルバーとEXE用のマルチサイズアイコン

通常起動ではウィンドウ左上とタスクバーに同じアイコンを設定します。

## Windows EXEの作成

ビルド時のみPyInstallerが必要です。

```powershell
python -m pip install pyinstaller
.\build_exe.ps1
```

完成したアプリは `dist\ScheduleBoard\ScheduleBoard.exe` です。ビルドスクリプトはEXEへのICO埋め込みと、実行時にTkinterが読むPNG/ICOの同梱を行います。

EXE版の `schedules.json` と `completed_tasks.jsonl` は、再起動後も保持されるようEXEと同じフォルダーに保存します。アプリのフォルダーには書込み権限が必要です。

## 主な機能

- 「追加」メニューからの親子スケジュール管理
- 画面切替専用の「タスク＆ガント」「TODOリスト」タブと、モード別に整理した操作メニュー
- 親単位、または同じ親に属する子同士の並べ替え
- 削除前の確認と、親削除時の子タスク一括削除
- 親の表示設定と連動した子ガントの表示、子ごとの個別表示設定
- 親の折りたたみ・展開
- 親完了時の子タスク一括完了と完了ログ
- 0～100%、または任意の分母を使った進捗入力とガント上の進捗表示
- 各行の着手日記録と `MM/DD` 表示。未着手で0より大きい進捗を保存した場合は、その日の日本標準時を自動記録
- 年・月・日を分けた日付入力、Space／`-`／`/`による次項目への移動、`YYYY-MM-DD`の貼り付け、カレンダー選択
- 親子構造を保ったままスケジュールとTODOを相互移動
- タスク名・期限・通知有無を持つTODOの手動追加、子TODO追加、編集、並べ替え
- 通知ONかつ期限が当日以前のTODOを、TODOに残っている間1時間ごとにWindows通知
- 日本標準時の現在日を基準にした遅延日数表示
- 親子ツリー、日付、着手日、進捗、遅延、ガントバーを再現する `.xlsx` 出力
- 縦スクロール、タスク列幅のドラッグ調整
- 「表示設定」による30～72pxの行高さ変更（次回起動時も保持）
- Yu Gothic UIを使った日本語表示と、画面幅に追従するモダンなカード型UI

## TODOの移動規則

- 親または子を選んで移動すると、親子関係が分断されないよう親グループ全体を移動します。
- スケジュールからTODOへ移すと、期限は各行の開始日、通知はOFFになります。必要な項目だけTODO画面でONに切り替えられます。
- スケジュール由来のTODOは元の期間、進捗、表示、着手日を内部に保持します。TODOで期限を変えて戻した場合は、新しい期限を開始日にし、元の期間日数を維持して終了日をずらします。
- 手動で追加するTODOも通知の初期値はOFFです。スケジュールへ移す場合は、開始日と終了日を期限と同日にし、進捗0・未着手で作成します。

Windows通知はWindows標準の通知領域機能を使います。Windows側で通知や通知領域の表示が無効な場合、通知は表示されません。

## データ互換性

変更は `schedules.json` に保存され、起動時に読み込まれます。旧形式の `entries` とバージョン2データは自動的に読み込まれ、次回保存時に着手日、TODO、通知状態、表示設定を含むバージョン3へ更新されます。未知の将来バージョンは情報を失う変換を避けるため、読み込みを中止します。

完了したタスクは従来どおり `completed_tasks.jsonl` に記録されます。従来の必須項目を維持したまま、ID、親ID、種別、進捗、着手日などの情報を追加しています。

## データ保護

- 保存内容は同じフォルダーの一時ファイルへ書き、`flush` と `fsync` で同期してから原子的に置き換えます。
- 直前の正常な内容を `.bak` として1世代保持し、主ファイルが欠損・破損している場合は起動時に自動復旧します。
- 完了ログも追記ではなく同期付きの原子更新を行い、途中で切れた最終行が残っても以前の正常な記録を救済します。
- タスク完了時は処理中の内容をジャーナルへ先に保存し、アプリやOSが途中で停止しても次回起動時に予定表と完了ログを整合させます。

これらは強制終了や電源断に対する実用上の保護です。同じデータフォルダーを使うアプリの同時複数起動は想定していません。ストレージ機器そのものの故障やフォルダー全体の消失には備えられないため、重要なデータは別媒体にもバックアップしてください。

## テスト

```powershell
python -B -m unittest discover -v
```

Windowsの実Tk環境では、フォント、行高、列位置、選択表示、折りたたみ、スクロール、入力ダイアログもテストします。
