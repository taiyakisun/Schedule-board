# sch_gantt

親子グループ、進捗、遅延表示、Excel出力に対応した簡易ガントチャートアプリです。

## 実行方法

- 前提: Python 3.10以降（tkinter同梱）
- 実行: `python sch_gantt_main.py`
- 外部Pythonパッケージは不要です。

## 主な機能

- 「親を追加」「子を追加」による親子スケジュール管理
- 親単位、または同じ親に属する子同士の並べ替え
- 削除前の確認と、親削除時の子タスク一括削除
- 親の表示設定と連動した子ガントの表示、子ごとの個別表示設定
- 親の折りたたみ・展開
- 親完了時の子タスク一括完了と完了ログ
- 0～100%、または任意の分母を使った進捗入力とガント上の進捗表示
- 日本標準時の現在日を基準にした遅延日数表示
- 親子ツリー、日付、進捗、遅延、ガントバーを再現する `.xlsx` 出力
- 縦スクロール、タスク列幅のドラッグ調整

## データ互換性

変更は `schedules.json` に保存され、起動時に読み込まれます。旧形式の `entries` は、子を持たない親タスクとして自動的に読み込まれます。次回保存時に、安定IDを含むバージョン2の親子形式へ更新されます。

完了したタスクは従来どおり `completed_tasks.jsonl` に追記されます。従来の必須項目を維持したまま、ID、親ID、種別、進捗などの情報を追加しています。
